# Module 8: Debugging AI Code

## Why This Matters

AI-generated code often works, but sometimes it doesn't. Knowing how to debug helps you:
- Quickly identify what went wrong
- Fix issues without regenerating everything
- Learn from mistakes to write better prompts

---

## What You'll Learn

1. **Common Mistakes** - Frequent AI code issues
2. **Debugging Techniques** - Tools and strategies
3. **Reading Tracebacks** - Understanding error messages
4. **Testing** - Verifying code works correctly

---

## The AI Coder Perspective

When you see:
```
Traceback (most recent call last):
  File "app.py", line 42, in process_data
    result = data['key']['nested']
KeyError: 'nested'
```

You'll know exactly what went wrong and how to fix it.
