# Module 5: Control Flow

## Why This Matters

Control flow determines how your program makes decisions and repeats actions. Understanding these patterns helps you:
- Read conditional logic in AI-generated code
- Understand error handling strategies
- Know when to use which loop construct

---

## What You'll Learn

1. **Conditionals** - if/elif/else and truthiness
2. **Loops & Iteration** - for, while, and comprehensions
3. **Exceptions** - try/except and error handling
4. **Context Managers** - The `with` statement

---

## The AI Coder Perspective

When you see:
```python
with open(file) as f:
    for line in f:
        if line.strip():
            try:
                process(line)
            except ValueError:
                continue
```

You'll understand every control flow construct here.
