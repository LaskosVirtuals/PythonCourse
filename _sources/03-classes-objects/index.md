# Module 3: Classes and Objects

## Why This Matters

AI-generated code is full of classes. Understanding them helps you:
- Read and modify AI code confidently
- Understand error messages about objects
- Know when to ask AI to use a class vs. functions

---

## What You'll Learn

1. **Reading class definitions** - What all the parts mean
2. **Inheritance patterns** - `super()`, mixins, ABCs
3. **Dataclasses** - The modern shortcut AI loves
4. **Common OOP patterns** - Factory, Builder, Singleton

---

## The AI Coder Perspective

When you see:
```python
class UserService(BaseService):
    def __init__(self, db: Database):
        super().__init__()
        self.db = db
```

You'll understand exactly what each part does.
