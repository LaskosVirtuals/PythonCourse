# Module 1: Project Anatomy

## Why Start Here?

When AI generates a Python project, it creates files and folders that may look mysterious:

```
my_project/
    src/
        mypackage/
            __init__.py
            main.py
    tests/
    pyproject.toml
    requirements.txt
```

Understanding this structure helps you:
- Know where to find things
- Understand how pieces connect
- Debug "file not found" errors
- Guide AI to create proper project structures

---

## What You'll Learn

1. **Common project layouts** - How Python projects are organized
2. **Key files** - What `__init__.py`, `pyproject.toml`, and `requirements.txt` do
3. **Entry points** - How Python knows where to start running code
4. **Virtual environments** - Why they exist and how to use them
