# Module 6: Data Structures

## Why This Matters

Python's built-in data structures are powerful and appear everywhere in AI-generated code. Understanding them helps you:
- Choose the right structure for each task
- Understand performance implications
- Read complex data manipulations

---

## What You'll Learn

1. **Core Collections** - Lists, dicts, sets, tuples
2. **Specialized Collections** - Counter, defaultdict, deque
3. **Strings & Bytes** - Text vs binary data
4. **None & Optional** - Handling missing values

---

## The AI Coder Perspective

When you see:
```python
from collections import defaultdict, Counter
result = defaultdict(list)
for item in items:
    result[item.category].append(item)
counts = Counter(word for line in text for word in line.split())
```

You'll understand why these patterns are used.
