# Python for AI Coders

**Learn Python the way AI coders think: from architecture to syntax.**

---

## Who Is This For?

You've built software with AI assistants like Claude, Copilot, or ChatGPT. You can describe what you want and get working code. But when something breaks, or when you want to understand *why* the AI wrote code a certain way, you hit a wall.

This course is for you.

---

## A Different Way to Learn

Traditional Python courses teach **bottom-up**:
> Variables → Data types → Operators → Control flow → Functions → Classes → Architecture

We teach **top-down**:
> How projects are organized → How imports work → How classes fit together → How functions behave → The syntax details

**Why?** Because when you look at AI-generated code, you see the big picture first. You see files, imports, classes. The syntax details come later.

---

## What You'll Learn

After this course, you'll be able to:

- **Read any Python code** and understand what it does
- **Debug AI-generated code** when it breaks
- **Guide AI better** by knowing the right technical terms
- **Recognize patterns** that AI commonly generates
