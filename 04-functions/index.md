# Module 4: Functions

## Why This Matters

Functions are everywhere in Python code. Understanding them deeply helps you:
- Read complex function signatures
- Understand what decorators do
- Write better prompts for AI (using correct terminology)

---

## What You'll Learn

1. **Function signatures** - All the ways to define parameters
2. **Decorators** - What `@something` means
3. **Closures** - Functions returning functions
4. **Type hints** - Reading type annotations

---

## The AI Coder Perspective

When you see:
```python
@cache
def process(data: List[int], *, validate: bool = True) -> Optional[Dict]:
```

You'll understand every part of this.
